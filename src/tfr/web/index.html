      Quick guide

      Using TFR

      Worlds

      Tap a world ball, choose a world in Settings, or swipe sideways to switch.

      Connected Unread messages Disconnected Current world

      Reading and sending

      • Type in Send to world… and tap Send or the keyboard send key.
      • History restores an earlier command for editing; it never sends automatically.
      • Scroll up to read. Return to live jumps back to new output.
      • Tap a message for timestamp, provenance, and content details.
      • Tap or drag the transcript to dismiss the keyboard when you want more reading room.

      Connection and notifications

      LIVE means this app is connected to the Gateway. Reconnecting and history notices explain temporary gaps. Notifications are configured per device in Settings and contain no message text.

      Display

      Settings controls text size, line wrapping, spelling suggestions, motion, Effects Lab, diagnostics, pairing, and device management.
